What it checks

🔍

Missing values

Detects blank or null cells per column with percentage impact scores.

♻️

Duplicate rows

Finds exact duplicate records that inflate datasets and skew analysis.

📋

Wrong format

Validates emails, dates, and phone numbers against expected patterns.

⚠️

Invalid characters

Catches dangerous or unintended characters like \, <, >, |, and more.

🔢

Mixed data types

Spots columns with both numeric and text values causing formula errors.

📊

Statistical outliers

Flags values more than 3 standard deviations from the column mean.

🔒

Mandatory columns

Checks that user-defined required columns exist and are not empty.

🤖

AI deep analysis

Claude AI scans for semantic issues, logic errors, and inconsistency patterns.
